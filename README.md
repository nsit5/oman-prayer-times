## طريقة التثبيت (Chrome / Edge / Brave)

1. افتح المتصفح واذهب إلى: `chrome://extensions`
2. فعّل **وضع المطور** (Developer Mode) من الزاوية العلوية
3. اضغط **"تحميل غير مضغوط"** (Load unpacked)
4. اختر مجلد `oman-prayer-extension` بعد فك الضغط
5. ستظهر الإضافة في شريط الأدوات 🎉

---

## طريقة الاستخدام

### الإعداد الأولي
1. اضغط على أيقونة الإضافة
2. اذهب إلى تبويب **⚙️ الإعدادات**
3. اختر **ولايتك** من القائمة
4. اختر **المظاهر** المفضل
5. فعّل الإشعارات حسب رغبتك

### تخصيص الإقامة
- اذهب إلى تبويب **⏱ الإقامة**
- اضبط وقت الانتظار (بالدقائق) لكل صلاة

### النافذة العائمة
- تظهر تلقائياً عند زيارة موقع وزارة الأوقاف
- يمكن سحبها وتحريكها في أي مكان
